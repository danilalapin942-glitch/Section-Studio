Section Studio 1.0

Распакуй весь архив в отдельную папку.
Запуск: Start_Section_Studio.bat
Нужны Python 3.10+ и полный OpenVSP 3.51.x.
В программе: Настроить OpenVSP → выбрать vspscript.exe.
Открой VSP3 → проверь выбор тел и единицы исходного файла.

Проверка MachLine: выбери решатель, M, α/β и offset → включи проверку
во время редактирования → «Проверить TRI для MachLine».
Для готового ASCII TRI можно выбрать исходные единицы и открыть файл.
Ремонт: предупреждение у внутренней станции → предел смещения в ft →
«Автоподбор и проверка» → осмотри результат → «Применить ремонт».
«↶ Отмена» возвращает форму. Остаточные риски показаны отдельно.
Режим VSPAERO и его гибридная проверка сохранены.
Сохрани JSON (продолжение работы и история) и VSP3 (геометрия OpenVSP).

Без Python: Section_Studio.html; ремонт импортированного VSP3 требует OpenVSP.
Инструкция: README.txt. Разбор MachLine: MachLine_1.0_notes.txt.
Проверки: Validation.json. Пример частичного ремонта: Examples/MachLine_*.
Программа оценивает риски; Cp и АДХ не рассчитывает.
