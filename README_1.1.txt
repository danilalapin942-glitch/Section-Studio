SECTION STUDIO 1.1 — совместное редактирование фюзеляжа и мотогондол
30 октября 2026

ЗАПУСК

1. Распакуй весь архив в отдельную папку.
2. Нужны Python 3.10+ и полный OpenVSP 3.51.x. Дополнительные Python-пакеты
   и Python SDK OpenVSP не нужны.
3. Запусти Start_Section_Studio.bat. Окно запуска оставь открытым.
4. В браузере: «Настроить OpenVSP» → выбери vspscript.exe из полной папки VSP.
5. Открой VSP3 → проверь выбранные Fuselage/Gondola и исходные единицы.
6. Для быстрого знакомства открой Examples/CH1_1.1_ready.json:
   в нём уже есть реальные поверхности крыла, пары зазоров и защита носа.
7. Сохраняй JSON для продолжения работы и VSP3 для OpenVSP.
   Скачивание результата не перезаписывает исходный файл на диске.

Linux: python3 section_studio_server.py, затем подключи установленный vspscript.
Требуется полный комплект OpenVSP и его системные библиотеки.
Section_Studio.html работает отдельно как редактор без нативных проверок.
Нативные проверки, защищённое сохранение и применение подгонки импортированного
VSP3 требуют локального запуска и OpenVSP 3.51.x. MachLine в архив не включён.

ШЕСТЬ ДОПОЛНЕНИЙ 1.1

• Внутренние ветви входа и сопла в корпусах Free XSec Order сохраняются
  в исходном порядке. Их можно выбирать и редактировать отдельно от оболочки.
• Боковые зеркальные мотогондолы подгоняются к корню крыла и внутренней
  стороной к фюзеляжу. Крыло, его профиль, положение и размах не меняются.
• Вкладка «Стыки и паспорт»: минимальное расстояние между треугольниками
  нативной 3D-сетки, отдельные зазоры/допуски каждой пары и временное уточнение.
• Ограниченный ремонт 1, 3, 5 или 7 станций: предпросмотр, нативная проверка,
  защита границ и соседних компонентов, отмена и журнал.
• Защищённые интервалы X и сравнение поверхностей после повторного чтения
  двух VSP3 в OpenVSP. Нарушение защиты блокирует обычное сохранение VSP3.
• Паспорт JSON: габариты, опорные Sref/bref/cref из файла, площади CompGeom,
  категории граней TRI и результаты проверок с ограничениями точности.

Сохранены живые предупреждения VSPAERO/MachLine, проверка готовой TRI,
75 шаблонов сечений, прежние проекты JSON и режимы высоко/средне/низкоплана.

ВАЖНЫЕ ОГРАНИЧЕНИЯ

Точки минимума показаны для выбранных пар на конкретной триангуляции.
Разность двух сеток показывает чувствительность, но не доказывает точность CAD.
Предпросмотр редактора приближённый; решение о применении импортированной
подгонки принимается только после проверки нативной сетки и сохранения формы.

Категории площади назначаются вручную связным плоским участкам TRI.
Все неназначенные грани пока считаются внешними. Площадь CompGeom включает
внутренние стенки и условные крышки; она отдельно от площади размеченной TRI.
Единственная «чистая внешняя омываемая площадь» автоматически не заявляется.

Изменение количества станций требует приближённого сопоставления ветвей по X.
Плоские торцы с постоянным X могут не иметь однозначного соответствия.
Несопоставленные точки защищённой зоны блокируют сохранение, а не дают успех.
Подгонка повёрнутых боковых тел и произвольной топологии не поддерживается.

Программа оценивает геометрические и численные риски. Cp, АДХ, отрыв,
скачки уплотнения и сертификацию расчётной геометрии она не выполняет.

ПРОВЕРКА ВЕРСИИ

Проверены нативный OpenVSP 3.51.0 Linux, Chromium 131, Python и JavaScript.
Нативные испытания включают Free-вход/сопло CH-1, сохранение крыла/фюзеляжа,
сопряжение двух зеркальных гондол, площади, зоны защиты и ремонт трёх станций.
Windows BAT и системный диалог Windows в этой среде не запускались.

ЕСЛИ НЕ РАБОТАЕТ

Python required: установи Python 3.10+ с launcher или Add Python to PATH.
Браузер не открылся: скопируй адрес http://127.0.0.1:… из окна запуска.
OpenVSP не найден: выбери vspscript.exe из полного комплекта с его DLL.
Проверка неполная: смотри причину; неполная проверка не разрешает применение.
Нативная операция ограничена 180 секундами на один запуск vspscript.
Для остановки сохрани JSON, затем закрой окно запуска или нажми Ctrl+C.
