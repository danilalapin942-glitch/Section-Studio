CH-1 — демонстрация Section Studio 1.2

CH1_1.2_ready.json содержит исходный CH1.vsp3 без геометрических правок,
подготовленные реальные поверхности Wing, защиту носа и пары:
Fuselage / Gondola: минимум 0,003 ft, допуск 0,0001 ft;
Gondola / Wing: минимум 0,006 ft, допуск 0,0001 ft.

Открой JSON → «Стыки и паспорт» → «Проверить зазоры и площади».
Автодоводка: изменяемая только Gondola, бюджет 0,05 ft, штатное полное окно X,
6 итераций максимум. «Подобрать по 3D-зазорам» → просмотри → примени.
При проверке в OpenVSP 3.51.0 Linux потребовалась одна итерация.
Итог на уточнённой TRI:
Fuselage / Gondola: 0,0043217157 ft;
Gondola / Wing: 0,0060000000 ft;
проверенный max изменения Gondola: 0,0015302462 ft;
Wing и Fuselage: 0, их XML оставлен без изменений.
Условия демонстрации не являются производственными допусками самолёта.

CH1_1.2_repaired.json/.vsp3 — отдельный результат этой операции.
CH1_1.2_validation.json — сокращённые фактические результаты native-проверки.
CH1_1.2_inserted_stations_compare.json — сравнение с отдельным примером 1.1,
где у Gondola 33→48 станций: max отклонение формы около 0,0334424 ft,
защищённый вход X=18,4…20,59 ft численно неизменен (порядка 1e-14 ft).
Сравнение использует конечную двустороннюю проекцию, не строгий Hausdorff.

Three_bodies_rotation_example.vsp3 — искусственная проверочная компоновка
с дополнительным Aux_Body, поворотами [12,17,26]° и Origin=0,25.
Она показывает дерево и сохранение нескольких правок, не самолётную геометрию.
Исходный Prepared_models/CH1.vsp3 оставлен без изменений.
