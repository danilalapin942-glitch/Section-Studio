# Section Studio 1.2.2

Редактор сечений OpenVSP с настройкой входов и сопел, отдельным редактором контура и запуском расчётных серий.

**[Скачать Section Studio 1.2.2](https://github.com/danilalapin942-glitch/Section-Studio/releases/tag/v1.2.2)** · [Архив в репозитории](releases/1.2.2/Fuselage_Section_Studio_v122.zip) · [История изменений](CHANGELOG.txt)

## Запуск

1. Распакуйте весь Fuselage_Section_Studio_v122.zip в отдельную папку.
2. Нужны Python 3.10+ и полный OpenVSP 3.51.x с DLL.
3. Запустите Check_Setup.bat, затем Start_Section_Studio.bat.
4. Укажите vspscript.exe в настройках OpenVSP. Выберите единицы исходного VSP3.
5. Для расчётных серий подключите MachLine во вкладке «Расчёты» и задайте режимы и опорные величины.

Подробности: [README.txt](README.txt), [START_HERE.txt](START_HERE.txt), [руководство 1.2.2](User_guide_1.2.2.txt). Автономный HTML поддерживает редактирование; нативные операции и расчёты требуют локального сервера и подключённых вычислителей.

## Новое в 1.2.2

- Настройка 22 параметров Engine Model OpenVSP 3.51 с нативными пределами и зависимостями.
- Вставка и удаление нескольких узлов контура.
- Отдельный черновик сечения: ручки Безье, точные координаты, локальная отмена, проверка самопересечений и применение одним действием.
- Расчётные серии VSPAERO/MachLine: процессы, отмена, история, CSV, контрольные суммы и отдельные статусы геометрии, завершения и сходимости.

## Проверки и границы

Перед публикацией 2 ноября 2026 года независимо пройдены **124 Python-теста и пять наборов JavaScript-проверок**. Два нативных интеграционных теста OpenVSP пропущены. Также проверены синтаксис, JSON/XML, манифест, целостность ZIP и вложенного расчётного архива. Собранный HTML совпадает с исходниками. Сканирование известных форматов секретов и персональных путей совпадений не выявило.

В Windows с Python 3.12.14 проверены справка BAT, запуск локального сервера, выдача страницы, журнал и повторное использование работающего экземпляра с изолированными настройками. **Интерактивный браузер, нативный OpenVSP и решатели потока при публикации не запускались.** Подробности: [протокол](releases/1.2.2/publication_verification.json). Validation.json содержит предоставленные автором результаты Linux.

**Готового самолёта с полным расчётным допуском в этом выпуске нет.** MQ-20 не получил полного допуска; учебный одиночный корпус Body_control не прошёл допуск сеточной сходимости. Их отрицательные отчёты сохранены как примеры диагностики. Они не подтверждают расчётную готовность модели и не являются проверкой аэродинамической точности.

Engine Model описывает геометрию входов/сопел, без расхода и тяги. Полная интеграция с ядром RepairMach остаётся следующим этапом. Остальные ограничения: [README.txt](README.txt), [Validation.json](Validation.json).
