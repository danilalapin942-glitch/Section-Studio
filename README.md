# Section Studio 1.0

Редактор сечений фюзеляжей и мотогондол для моделей OpenVSP: библиотека шаблонов, редактирование формы, сопряжение с крылом, предварительная оценка рисков сетки и локальный ремонт.

## Запуск в Windows

1. Скачайте `Fuselage_Section_Studio_v10.zip` и распакуйте его целиком в отдельную папку.
2. Установите **Python 3.10+** с Python Launcher или добавлением Python в PATH и полный **OpenVSP 3.51.x** для Windows. Дополнительные Python-пакеты не нужны.
3. Запустите **`Start_Section_Studio.bat`**. Программа откроется в браузере; окно запуска оставьте открытым.
4. В приложении нажмите «Настроить OpenVSP» и выберите `vspscript.exe` из полной папки OpenVSP.
5. Откройте VSP3, выберите редактируемый компонент и проверьте единицы. Сохраняйте результат отдельным файлом.

Для автономного редактора можно открыть `Section_Studio.html`; операции, использующие OpenVSP, требуют локального сервера и OpenVSP. Подробности: [README.txt](README.txt), [START_HERE.txt](START_HERE.txt), [руководство](Editor_manual_0.8.txt).

Python: https://www.python.org/downloads/windows/ · OpenVSP: https://openvsp.org/

## Что входит в 1.0

- Библиотека 75 шаблонов, редактор сечений и работа с проектами JSON/VSP3.
- Средства сопряжения с крылом и проверки поверхности через OpenVSP.
- Оценка рисков MachLine при редактировании с учётом M, α/β и смещения контрольных точек.
- Проверка TRI-сетки, подсветка опасных панелей, отчёт и шаблон входных данных.
- Автоподбор ограниченного локального ремонта, проверка результата, применение и отмена.
- Исходники, тесты, примеры, подготовленные модели и описание исследованных исходников MachLine.

## Ограничения и проверки

Предварительные проверки не заменяют аэродинамический расчёт. Программа не рассчитывает Cp и не запускает решатель потока. Ремонт может оставить остаточные риски; приложение показывает их отдельно. См. [MachLine_1.0_notes.txt](MachLine_1.0_notes.txt) и [README.txt](README.txt).

Перед публикацией в этом репозитории 28 октября 2026 года независимо пройдены **42 Python-теста и два набора JavaScript-проверок**, проверки синтаксиса, JSON/XML, целостности архива и манифеста. Собранный HTML совпадает с исходниками. Поиск известных форматов секретов и персональных путей совпадений не дал. **Интерактивный Windows BAT, браузерный интерфейс, OpenVSP и аэродинамический решатель при этой публикации не запускались.** `Validation.json` содержит исторические результаты автора. [Подробный протокол](releases/1.0/publication_verification.json).
