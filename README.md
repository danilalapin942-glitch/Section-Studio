# Section Studio 1.2.1

Редактор сечений и сопряжений для моделей OpenVSP: библиотека шаблонов, работа с внутренними контурами, проверка геометрии и ограниченный ремонт.

## Запуск в Windows

1. Скачайте Fuselage_Section_Studio_v121.zip и распакуйте его целиком в отдельную папку.
2. Нужны **Python 3.10+** и полный **OpenVSP 3.51.x**. Дополнительные Python-пакеты не требуются.
3. Сначала запустите **Check_Setup.bat**, затем **Start_Section_Studio.bat**. Окно запуска оставьте открытым.
4. В приложении выберите vspscript.exe из полного комплекта OpenVSP и откройте VSP3 или проект JSON.
5. Сохраняйте результаты отдельными файлами. Автокопии дополняют обычное сохранение.

Автономный редактор: Section_Studio.html. Восстановление с диска и операции OpenVSP требуют локального сервера.
Подробности: [README.txt](README.txt), [START_HERE.txt](START_HERE.txt), [руководство 1.2.1](User_guide_1.2.1.txt), [руководство 1.2](User_guide_1.2.txt).

Сохранены возможности 1.1/1.2: внутренние контуры, несколько корпусов и повороты, карта зазоров, ремонт участка, защищённые зоны и геометрический паспорт.

## Проверки и ограничения

Перед публикацией 1 ноября 2026 года независимо пройдены **98 Python-тестов и четыре набора JavaScript-проверок**, проверки синтаксиса, JSON/XML, целостности ZIP и манифеста. Все **119 исходных файлов** и архив сохранены без изменений; собранный HTML совпадает с исходниками. Сканирование известных форматов секретов и персональных путей совпадений не выявило.

В Windows с Python 3.12.14 проверены справка BAT, запуск сервера без открытия браузера, выдача страницы и повторный запуск работающего экземпляра. Настройки и журналы проверки изолированы. **Интерактивный браузер, нативный OpenVSP и решатели потока при публикации не запускались.** Полная проверка зависимостей на целевой машине выполняется через Check_Setup.bat. [Протокол независимых проверок](releases/1.2.1/publication_verification.json).

Validation.json содержит предоставленные автором результаты Linux/OpenVSP. Программа оценивает геометрические риски; вычисление Cp/АДХ и интеграция с RepairMach остаются следующими этапами. Ограничения обрезки, точности карты и ремонта описаны в [README.txt](README.txt).
