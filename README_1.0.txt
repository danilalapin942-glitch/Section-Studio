SECTION STUDIO 1.0 — редактирование корпусов, риски MachLine и локальный ремонт
11 октября 2026

ЗАПУСК

1. Распакуй весь архив в отдельную папку.
2. Установи Python 3.10+ и полный OpenVSP 3.51.x для Windows. Дополнительные
   Python-пакеты не нужны. Python: https://www.python.org/downloads/windows/
3. Запусти Start_Section_Studio.bat. Программа откроется в обычном браузере.
   Окно запуска оставь открытым: файлы обрабатываются на твоём компьютере.
4. Нажми «Настроить OpenVSP» и выбери vspscript.exe из полной папки OpenVSP.
   Например: C:\OpenVSP-3.51.0\vspscript.exe. Выбранный путь запоминается.
5. Открой VSP3, выбери фюзеляж/мотогондолу и проверь исходные единицы.
   В редакторе и экспортируемом MachLine TRI все размеры приведены к футам.
6. Если импорт требует преобразования сечений, нажми «Подготовить и открыть
   через OpenVSP». Результат подставляется только после успешной проверки.
7. Сохраняй JSON для продолжения работы и VSP3 для дальнейшего моделирования.
   Исходный файл на диске не перезаписывается.

В Linux: python3 section_studio_server.py; укажи установленный vspscript.
Section_Studio.html можно открыть самостоятельно, без Python. В этом режиме
нет нативной проверки и применения ремонта импортированного VSP3.
Проверка готового TRI требует локального запуска, но не требует OpenVSP.
Исполняемый файл MachLine для диагностики не нужен и в архив не включён.

ЧТО ДОБАВЛЕНО В 1.0

Выбор решателя VSPAERO / MachLine; число Маха, углы α/β, формулировка,
тип и величина смещения контрольных точек (offset).
Во время редактирования оценивается наклон предварительных граней корпуса.
Есть отдельная проверка реальной TRI-сетки и загрузка готового ASCII TRI.
Ошибки и предупреждения отмечаются на 3D-виде сетки, отчёт скачивается в JSON.
Для локальной неровности «Автоподбор и проверка» строит ограниченную правку,
проверяет её в OpenVSP и предлагает применить подтверждённый результат.

Проверки привязаны к официальному MachLine v4.0, commit
d62befad9d2d62e30106440e29862ebac7dc362c. Подробный разбор: MachLine_1.0_notes.txt.
Программа оценивает геометрические и численные риски. Она не рассчитывает Cp,
АДХ, скачки уплотнения, отрыв или вероятность возникновения пика давления.

ПРОВЕРКА MACHLINE ВО ВРЕМЯ РЕДАКТИРОВАНИЯ

1. Выбери MachLine в блоке проверки рисков.
2. Задай M, α, β и параметры контрольных точек; включи автоматическую проверку.
   Углы задаются в градусах. X направлен к хвосту, Z вверх. Скорость в JSON:
   [cos(α)cos(β), sin(β), sin(α)cos(β)]. Вектор также показан в интерфейсе.
3. Редактируй сечение. Предупреждения обновляются во время ввода и перемещения
   точек; затем выполняется проверка всей длины выбранных корпусов.
4. Нажми «Проверить TRI для MachLine» для проверки фактических треугольников.
   Предварительные грани редактора и окончательное сглаживание OpenVSP
   могут иметь разные нормали. Успех предварительной проверки недостаточен.

При M > 1 вычисляется Q = 1 − M²(n·c)² для нормали панели n и единичного
направления скорости c. В исследованном MachLine Q < 0 и |Q| < 1e−12 вызывают
STOP. M = 1 также запрещено. Площадь ниже 1e−12 в единицах входной TRI вызывает
STOP; экспорт Studio выполняется в ft, поэтому площадь проверяется в ft².
Порог 0 < Q < 0,05, близость к M = 1 и некоторые другие предупреждения —
эвристики Studio. Их происхождение указано в отчёте.

РЕАЛЬНАЯ TRI-СЕТКА

Из VSP3 экспортируются полные объёмные поверхности Fuselage, Pod, Stack,
Ellipsoid, BOR и Wing. Верх и низ профиля крыла сохраняются. Диагностические
наборы и имена меняются только во временной копии в памяти OpenVSP.
Исходные Set_1/Set_2, размах, положение и профиль крыла остаются исходными.
Настройки наборов VSPAERO и его Mode в этом экспорте не используются.
Список исключённых компонентов показывается рядом с сеткой.

Этот экспорт служит для проверки исходной геометрии; он не заменяет подготовку
окончательной объединённой сетки с согласованными пересечениями и следом.
Для проверки сетки из другого генератора нажми «Проверить готовый TRI…», выбери
единицы ft/m/mm/in и файл. Поддерживается текстовый Cart3D TRI: узлы, треугольники
и необязательные теги. Двоичный TRI и поля решения не поддерживаются.
Внешние теги не сопоставляются компонентам текущего VSP3. Такой отчёт не является
проверкой ремонта модели и не разрешает применение правки её сечений.

Проверяются площадь, вытянутость, совпадения, обход/нормали, связность,
близость центров, критерии наклона MachLine и номинальное размещение контрольных
точек. Для Dirichlet смещение направлено внутрь от вершины по усреднённой
нормали; local масштабируется средней длиной соседних рёбер. Для Neumann
velocity используется прямое смещение от центроида наружу, даже при local.
Для Neumann mass flux точки расположены на панели; проверка offset не нужна.
Клонирование вершин на следе и итерационная правка контрольных точек в MachLine
не воспроизводятся: проверка offset имеет статус «номинальная».

После проверки можно скачать Mesh.tri, отчёт JSON и шаблон входа MachLine.
В шаблоне reference.area = 1 ft², reference.length = 1 ft, CG = [0,0,0] ft —
заглушки, которые надо заменить своими опорными данными. Настрой также след,
метод решения и прочие параметры. Шаблон не означает готовность к расчёту.
Малые числа записываются с десятичной точкой в мантиссе: 1.0e-7. Это обход
особенности JSON-парсера исследованного MachLine; не заменяй их на 1e-7.

АВТОМАТИЧЕСКИЙ ЛОКАЛЬНЫЙ РЕМОНТ

1. Нажми предупреждение о неровности продольного обвода или наклоне MachLine
   возле внутренней станции. Для торцов, кромок и топологии автоправки нет.
2. Задай максимальное смещение в ft. Дополнительный предел — 5% меньшего
   местного габарита; на управляющих точках оставляется запас 10%.
3. Нажми «Автоподбор и проверка». Исходная геометрия остаётся в редакторе.
   Программа перебирает несколько степеней сглаживания одной станции,
   выбирает ограниченный вариант и сравнивает две нативные сетки OpenVSP.
   Можно также раздельно построить предпросмотр и запустить проверку.
4. Просмотри пунктир исходного контура, оранжевый контур предложения и отчёт.
   Для ремонта MachLine наклон в реальной зоне должен уменьшиться минимум
   на 2% (не менее 0,05°). Проверяются новые/усиленные сеточные риски.
5. После успешной проверки нажми «Применить ремонт». «↶ Отмена» возвращает
   прежнюю форму. Остаточные ошибки и предупреждения показаны отдельно.
6. Сохрани JSON с историей и новый VSP3; проверь окончательную расчётную сетку.

Проверяется фактическое перемещение поверхности на 321 × 65 точках каждой
поверхности выбранного тела. Смещение вне зоны допускается только в пределах
1e−6 ft, в защищённой зоне — 1e−7 ft. Бюджет сравнивается с допуском 0,1% +
1e−7 ft. Конечная выборка может пропустить дефект между отсчётами.
Неполная проверка близости или offset блокирует применение.

Защищены торцы, повёрнутые станции, станции двигателя/внешних связей,
зона сопряжения с крылом, несовместимые параметры соседних контуров.
Можно вручную отметить «Защитить эту станцию от ремонта».
X и повороты станций, крыло и остальные компоненты не меняются.
Автоправка не меняет число Маха, offset, профиль или размах крыла, не закрывает
отверстия и не удаляет панели. Если модель или настройки изменились, прежний
предпросмотр и поздний ответ проверки не разрешают применение.
«Безопасный ремонт» означает прохождение перечисленных ограничений;
он может только уменьшить неровность, оставив риск при выбранном режиме.

РЕЖИМ VSPAERO

Сохранены анализ продольного обвода, проверка реальной vspgeom v3 и ремонт 0.9.
Режим «Настройки VSPAERO из VSP3» использует исходные наборы, Mode и симметрию.
«Гибрид» включает корпуса объёмными, Wing тонкими; Mode и половинная симметрия
отключены только в диагностической копии. Ремонт при активном Mode запрещён,
так как Mode может переопределять геометрию. Выбери гибридную проверку.
Разбор источников и критериев: VSPAERO_0.9_notes.txt.

РЕДАКТОР, ШАБЛОНЫ И СОПРЯЖЕНИЕ С КРЫЛОМ

Фюзеляж и мотогондола редактируются совместно по станциям и управляющим точкам.
Вкладка «Библиотека сечений» содержит 75 контуров из семи наших моделей.
Применение шаблона заменяет одну станцию, сохраняя положение и повороты.
Вкладка «Сопряжение с крылом» получает реальную выборку поверхности Wing из VSP3
и подгоняет корпус для высокоплана, среднеплана или низкоплана с заданным зазором.
Крыло сохраняется без правок. Перед применением проверь всю хорду и переходы.
Подробности этих функций и ручного офлайн-режима: Editor_manual_0.8.txt.
Набор шаблонов описывает наши геометрии, а не подтверждённые заводские обводы.
Экспериментальные аэродинамические данные NACA в этой работе не использовались.

ГРАНИЦЫ ПРОВЕРКИ

Лимиты: 200000 узлов, 150000 панелей, 64 МБ нативного файла сетки; готовый TRI
через интерфейс — до 40 МБ текста. Для поиска близости и offset — до 2 млн
кандидатов на проверку. Достигнутый предел отмечается, результат неполный.
Большая сетка может показываться прореженно; отчёт анализирует все её панели.
Проверка центра панели не измеряет минимальный пространственный зазор.
Полный поиск пересечений сетки, матрица влияния MachLine, её обусловленность,
GMRES, чувствительность АДХ к сетке и фактические Cp пока не реализованы.
Другой commit MachLine может иметь другие ограничения и поведение.

ПРОВЕРКИ ВЕРСИИ

Validation.json содержит результаты 1.0: 42 Python-теста, проверки JavaScript,
полный браузерный цикл ремонта, проверку TRI на шести геометриях в трёх режимах.
Четыре остановки подтверждены запуском неизменённого исходного MachLine;
два расчёта учебного тела при M = 0,5 и 2 завершились успешно. Приложение само
решатель потока не запускает. Продольное сглаживание и сохраняемость крыла
проверены в нативном OpenVSP 3.51.0 Linux и Chromium 131.
Windows BAT и системный диалог Windows в этой среде не исполнялись.
Результаты прежних версий сохранены в Validation_*_baseline.json.
В Examples/MachLine_* находится пример частичного ремонта с пояснением.
Upstream_sources.json фиксирует ссылки и SHA256 исследованных файлов.
Исходники: source/, *.py, native/; тесты: tests/.

ЕСЛИ НЕ РАБОТАЕТ

Python required: установи Python 3.10+ с launcher или Add Python to PATH.
Браузер не открылся: скопируй адрес http://127.0.0.1:… из окна запуска.
Локальное подключение остановлено: перезапусти BAT и открой новый адрес.
vspscript не запускается: выбери его из полной папки OpenVSP с нужными DLL.
OpenVSP занят: дождись завершения операции в другой вкладке приложения.
Нативная операция дольше 180 секунд останавливается без замены проекта.
Для остановки сохрани проект, затем закрой окно запуска или нажми Ctrl+C.
