SECTION STUDIO 1.2.1 — НАДЁЖНОСТЬ
1 ноября 2026

Выполнен этап 1.2.1: запуск, входы/сопла и восстановление проекта.
Возможности 1.2 сохранены. Запуск потока VSPAERO/MachLine и интеграция
с ядром RepairMach остаются последующими этапами.

БЫСТРЫЙ ЗАПУСК

1. Распакуй весь архив. Нужны Python 3.10+ и полный OpenVSP 3.51.x.
2. Check_Setup.bat проверит зависимости, HTTP, recovery, повторный запуск и OpenVSP.
3. Запусти Start_Section_Studio.bat; окно оставь открытым.
4. «Настроить OpenVSP» → vspscript.exe из полной папки OpenVSP с DLL.
5. Открой VSP3 или готовый проект из Examples.
6. Сохраняй JSON и отдельный VSP3. Автокопии работают дополнительно.

Linux: python3 studio_bootstrap.py --vspscript /путь/vspscript
Диагностика: та же команда с --self-test. Дополнительные Python-пакеты не нужны.
Section_Studio.html работает отдельно как редактор; дисковое автовосстановление
и native-проверки требуют локального сервера.

ИСПРАВЛЕНО

• Сопоставление реальной обрезанной поверхности входа/сопла с исходными
  станциями: To Lip, обычная To Face, дробный U, повороты и штатная Origin.
  У контрольного MQ-20 распознаны все 4296 граней; плавность проверена.
  Исходная геометрия для этого не изменяется.
• Порядок ключей JSON больше не вызывает ложное сообщение об изменённой
  системе координат. Реальное изменение исходного frame или торцов
  по-прежнему отклоняется.
• Настройки записываются атомарно и имеют settings.json.bak.
• Восстановление крупных проектов с диска после сбоя и смены localhost-порта:
  три проверенные копии с контрольной суммой. Повреждённый снимок пропускается.
• Загрузчик пишет launch.log, сохраняет traceback и понятные коды ошибок DLL.
  BAT проверяет Python, поддерживает соседний переносимый Python и оставляет
  ошибку на экране. Повторный запуск использует уже работающий экземпляр.

ВОССТАНОВЛЕНИЕ

Автокопия создаётся через 1,5 с после паузы; при непрерывном редактировании —
примерно раз в 10 с. Есть «Сохранить копию сейчас». Предел одной копии — 60 МБ.
После сбоя: запусти программу → «Автовосстановление проекта» → выбери имя
и время → «Восстановить». Затем выполни native-проверки заново.
Это три последние генерации, а не архив всех моделей. В отдельном HTML
сохраняй JSON вручную. Последние правки до завершения записи могут потеряться.

Копии, настройки и журналы по умолчанию находятся в %LOCALAPPDATA%\SectionStudio
или ~/.config/SectionStudio; путь диагностики печатается при запуске.
Исходные модели и вручную сохранённые файлы не перезаписываются.
При ошибке записи заголовок восстановления просит сохранить JSON вручную.

ПРОВЕРКИ И ГРАНИЦЫ

Проверены Python 3.12, Chromium 131 и native OpenVSP 3.51.0 под Linux:
CH1, MQ-20, MQ-28, Spirit Mosquito, обрезка To Lip/To Face, дробный U,
повороты, крупный JSON, аварийное завершение, новый порт и повреждённые копии.
Фактические результаты — Validation.json.

Нативный запуск Windows и выполнение BAT в cmd.exe здесь не испытывались.
Для целевого компьютера предусмотрен Check_Setup.bat. При ошибке сохрани
Setup_check.json, launch.log и текст окна запуска.

Отрицательные дополнительные поверхности, удлинённый и циклически повёрнутый
тракт могут остаться нераспознанными. Неполная проверка блокирует автодоводку.
Работающее сопоставление MQ-20 не гарантирует получение произвольного зазора
в заданном бюджете. Неудачная итоговая проверка не разрешает применение.

Цветная карта использует центры граней, а глобальный минимум — целые
треугольники. Точность аналитической поверхности между отсчётами не доказана.
Физическая омываемая площадь требует подтверждённых категорий и перекрытий.
Программа оценивает геометрические риски, не рассчитывает Cp/АДХ и не заменяет
сертификацию. Ранее запланированные функции следующих этапов здесь не заявляются.
