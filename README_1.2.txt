SECTION STUDIO 1.2 — сечения корпусов и пространственные стыки
31 октября 2026

ЗАПУСК

1. Полностью распакуй архив в отдельную папку.
2. Установи Python 3.10+ и полный OpenVSP 3.51.x. Сторонние Python-пакеты
   и Python SDK OpenVSP не требуются. OpenVSP и MachLine в архив не включены.
3. Запусти Start_Section_Studio.bat и оставь окно запуска открытым.
4. В браузере нажми «Настроить OpenVSP» и выбери vspscript.exe из его полной
   папки. Программа также ищет обычные каталоги установки автоматически.
5. Открой Examples/CH1_1.2_ready.json для знакомства или свой VSP3.
6. Сохраняй проект JSON для продолжения и отдельный VSP3 для OpenVSP.

Check_Setup.bat проверяет Python, локальный сервер, чтение/запись и фактический
запуск OpenVSP; результат сохраняется в Setup_check.json (путь печатается в окне запуска). В Linux:
python3 section_studio_server.py --self-test --vspscript /путь/vspscript
Обычный запуск: python3 section_studio_server.py.

Section_Studio.html можно открыть отдельно для редактирования. Нативные
проверки, защищённый экспорт и применение подгонки исходного VSP3 требуют
локального сервера и подключённого OpenVSP 3.51.x.

ШЕСТЬ УЛУЧШЕНИЙ 1.2

• Автодоводка всех заданных стыков по фактической нативной 3D-сетке:
  изменяемые корпуса, окно X, бюджет, проверка всех пар и защит до применения.
• Сравнение формы после вставки станций: исходные ID сечений и двусторонняя
  нативная проекция, включая плоские торцы с постоянным X.
• Контроль нормалей и приближённой кривизны нативных переходов.
  Намеренные кромки отмечаются отдельно и сохраняются при ремонте.
• Дерево компонентов: все поддерживаемые корпуса в проекте, любая пара
  в двух окнах сечений, одиночный корпус, повороты Rx/Ry/Rz и штатная Origin.
• Автоматические категории оболочки, внутренних ветвей и плоскостей двигателя
  с ручной поправкой и площадями по категориям. Неопределённые грани видны.
• Карта зазоров, быстрый Web Worker, фоновая нативная проверка после паузы,
  отмена процессов и отклонение устаревших результатов.

Сохранены подгонка к реальному профилю Wing, высоко/средне/низкоплан,
боковые зеркальные мотогондолы, Free-вход/сопло, ручной ограниченный ремонт,
предупреждения VSPAERO/MachLine, библиотека 75 сечений, Undo и журнал.
Крыло и его размах остаются опорными при ремонте корпусов.

ПОРЯДОК РАБОТЫ

Открой модель → проверь компоненты и единицы → задай пары и зоны защиты →
редактируй сечения или подгони корпус к крылу → выполни нативную проверку →
предложи автодоводку → просмотри разрез до/после → примени → сравни с исходником →
сохрани JSON, VSP3 и паспорт. Правки можно отменить.

ТОЧНОСТЬ И ОГРАНИЧЕНИЯ

Редактор работает в ft, площади в ft², углы в градусах. Единицы исходного VSP3
выбираются явно: ft, m, mm, in. 1 ft = 0,3048 m.
Редактируются FUSELAGE с Point, Circle, Ellipse и поддерживаемой EditCurve.
Другие кривые предварительно преобразуются через OpenVSP. Активные привязки,
нестандартная симметрия и модификаторы кривых могут ограничивать операции;
причина показывается без удаления неподдерживаемых параметров.

При повороте корпуса редактор показывает местные станции до общего поворота.
Нативные разрезы «Стыков» выполняются в общей плоскости X. Подгонка станций
с собственными pitch/yaw ограничена; общий поворот компонента учитывается.
Копии отражаются в общей XZ. Остальные Geom сохраняются в исходном XML.

Минимум пары относится к целым треугольникам конкретной TRI. Цветная карта
содержит расстояния от центров граней в ограниченной полосе; она не заменяет
глобальный минимум. Web Worker использует упрощённую поверхность редактора.
Нативные сравнение и плавность используют конечные выборки, без строгой
оценки ошибки аналитической CAD-поверхности между отсчётами.

Авторазметка подтверждается нативной параметризацией и плоскостями сечений.
При неоднозначной обрезке двигателя, как у проверенной мотогондолы MQ-20,
участок остаётся «не распознано», а плавность — непроверенной. Автодоводка
блокируется. Зазоры проверяются независимо; категории уточняются вручную.
CompGeom и размеченная полная TRI дают разные оценки площади. Назначение
расчётных крышек не доказывает физическую наружную обшивку.

Программа оценивает геометрические и численные риски. Она не вычисляет Cp,
АДХ, отрыв и скачки уплотнения и не сертифицирует расчётную модель.
Окончательная замкнутая сетка MachLine остаётся этапом 1.3.

ФАЙЛЫ И ПРОВЕРКА

User_guide_1.2.txt — подробная актуальная инструкция и лимиты операций.
Examples/CH1_1.2_ready.json — исходный CH-1, крыло, пары и защита носа.
Examples/CH1_1.2_repaired.json/.vsp3 — отдельный пример нативной доводки.
Examples/CH1_1.2_example.txt — условия примера и результаты.
Prepared_models/CH1.vsp3 — исходный CH-1, оставлен без изменений.
Validation.json — фактические результаты испытаний и ограничения.
Upstream_sources.json — версии и адреса изученных исходников.
source/, native/, tests/, *.py — исходники программы и тесты.
Документы прежних версий оставлены как история. Для 1.2 приоритет имеют
README.txt и User_guide_1.2.txt.

Проверены OpenVSP 3.51.0 Linux, Python 3.12 и Chromium 131. Испытания включают
четыре самолётные модели, CH-1, торцы, защиты, многокомпонентный проект,
повороты и отмену. Windows BAT включены, но нативный запуск под Windows
в этой среде не испытывался; начни с Check_Setup.bat.

Python required: установи Python 3.10+ с launcher или Add Python to PATH.
Браузер не открылся: скопируй http://127.0.0.1:… из окна запуска.
OpenVSP не найден: выбери vspscript.exe из полного комплекта с его DLL.
Не запускай BAT прямо из ZIP: распакуй всю папку, сохранив её структуру.
Неполная проверка: смотри причину; такой результат не разрешает применение.
Каждый запуск vspscript ограничен 180 с. Полное сравнение после вставки
станций может занимать минуту и более. Для остановки сохрани JSON и нажми
Ctrl+C в окне сервера.
