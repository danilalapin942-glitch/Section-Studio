ПОСЛЕДОВАТЕЛЬНОСТЬ РАСЧЁТА

main.f90 читает JSON; flow.f90 нормирует заданный вектор скорости и задаёт
число Маха, угол Маха и метрические матрицы сжимаемого потока.
TRI/STL читаются в mesh/surface_mesh; совпадающие узлы объединяются,
вычисляются панели, нормали, соседи, след и клонированные вершины.
panel_solver.f90 выбирает формулировку граничных условий, контрольные точки,
строит матрицу влияния и решает систему. Из интенсивностей особенностей
вычисляются скорости, затем давление выбранным правилом и интегральные силы.
Проверка формы до решения может обнаружить некоторые причины сбоя, но не
определяет обусловленность матрицы, сходимость или правильность вычисленных Cp.

ТОЧНЫЕ УСЛОВИЯ ИЗ КОДА

flow.f90, flow_init: отрицательное M отвергается; при M = 1 выполняется STOP.
Поток считается сверхзвуковым при M > 1. c = V / |V|; B = I − M²ccᵀ.

panel.f90, panel_calc_area: A = 0,5 |(p2−p1) × (p3−p2)|.
Если A < 1e−12, выводится «has zero area» и выполняется STOP.
Это абсолютный порог в единицах входной геометрии, не относительный допуск.
Studio проверяет TRI в футах и использует порог 1e−12 ft².

panel.f90, panel_calc_g_to_ls_transform: Q = nᵀBn = 1 − M²(n·c)².
При сверхзвуковом потоке |Q| < 1e−12 даёт «is Mach-inclined» и STOP;
Q < 0 даёт «is superinclined» и STOP. При Q > 0 преобразование содержит
множитель 1/√Q. Наклон панели θ = asin(|n·c|), угол Маха μ = asin(1/M).
Условие θ < μ относится именно к исследованной реализации. В исходниках
есть формулы сверхнаклонных панелей, но ветвь инициализации сейчас запрещает их.
Наличие этих формул не означает поддержку сверхнаклонной входной сетки.

tri.f90 и stl.f90: вершины с расстоянием < 1e−12 объединяются. Studio
воспроизводит это в ft перед проверкой топологии. После объединения могут
появиться схлопнутые грани. Четвёртое поле строки узла TRI игнорируется.
Теги частей не являются самостоятельными физическими граничными условиями.

КОНТРОЛЬНЫЕ ТОЧКИ

Поддержанные в интерфейсе формулировки из panel_solver.f90:
dirichlet-morino, dirichlet-source-free,
neumann-mass-flux, neumann-velocity.
Остальные экспериментальные формулировки в интерфейс не перенесены.
Стандартные настройки исходника: control_point_offset = 1e−7,
control_point_offset_type = direct.

Dirichlet: начальная точка у вершины смещается внутрь по усреднённой нормали.
Усреднение взвешено углами соседних треугольников. local умножает offset
на среднюю длину соседних рёбер; direct означает абсолютную длину.
Далее surface_mesh.f90 может корректировать направление смещения и клонировать
вершины при создании следа. Studio воспроизводит только начальные точки.
Neumann mass flux: точки в центроидах на панели, offset не используется.
Neumann velocity: центроид смещается наружу на прямую длину offset;
значение local не масштабирует длину в этой ветви исходника.

Studio проверяет номинальный отрезок смещения на пересечение с несоседними
треугольниками через BVH. Это эвристика, а не фактические окончательные точки
MachLine. Ограничения поиска и пропуски отмечаются и блокируют ремонт.

ОСОБЕННОСТЬ JSON-ПАРСЕРА И ПРОВЕРКА ЗАПУСКА

common/json.f90 задаёт real_fmt = '(ES30.14E3)' (строка 115),
string_to_double использует форматированное чтение (строка 2229).
В собранном исходном MachLine запись 1e-7 была прочитана как 1e-21;
при мантиссе с точкой, 1.0e-7, прочитано нужное 1e-7.
Studio экспортирует научную запись с десятичной точкой в мантиссе; форматтер
обходит дерево JSON и не заменяет содержимое строк или имена файлов.
Совместимость подтверждена строкой реального журнала о смещении 1.0000E-07.

STOP без кода в этой сборке MachLine возвращает код процесса 0.
Проверки учитывали сообщение STOP и solver_status_code в отчёте;
один код возврата 0 не является доказательством успешного расчёта.

ЭВРИСТИКИ STUDIO

0 < Q < 0,05 — приближение к характеристическому наклону.
|M−1| < 0,1 — предупреждение о трансзвуковой применимости линейной модели.
Offset > 10% √A — предупреждение о масштабе контрольной точки.
Offset < 32 ULP масштаба координат — возможная потеря смещения при сложении.
Резкий поворот/изменение площади соседних панелей, короткие переходы,
острые контуры и близость центров — геометрические причины для осмотра.
Эти пороги выбраны в надстройке, не являются критериями STOP или
сертификационными допусками MachLine. В отчёте указано происхождение критерия.

РЕАЛИЗАЦИЯ

source/machline.js: быстрый анализ предварительных граней корпуса при правке;
64 точки по контуру, четыре продольных интервала на каждую пару станций.
Такая выборка не совпадает со сглаженной поверхностью и сеткой OpenVSP.
native/machline_mesh.vspscript: диагностический экспорт полного объёмного TRI
через OpenVSP 3.51. Полные Wing сохраняют верхнюю и нижнюю ветви профиля.
machline_audit.py: чтение/объединение узлов, топология, Q, номинальный offset.
section_studio_server.py: локальный API проверки VSP3 и готового внешнего TRI.
source/repair.js и native_audit.py: ограниченное сглаживание и проверка ремонта.

Автоправка меняет одну внутреннюю станцию совместимой параметризации.
Бюджет не больше 5% меньшего местного поперечного габарита; есть запас
на нативное сглаживание. Предварительный целевой угол должен снизиться на 5%.
Для MachLine нативный угол в зоне должен снизиться минимум на 2%, не менее
0,05°. Новые/усиленные сеточные риски и превышение бюджета запрещают применение.
X, повороты, крыло, размах и остальные компоненты сохраняются. Защищены
торцы, двигательные/связанные станции и область сопряжения с Wing.
Изменение M, offset, отверстий, топологии и произвольное удаление панелей
не являются автоматическим ремонтом. Применение и отмена остаются явными.

ПРОВЕРКИ И ПРАКТИЧЕСКИЙ РЕЗУЛЬТАТ

42 Python-теста: аналитические границы Q, sonic STOP, площадь, объединение
узлов, топология между частями, номинальные точки, единицы и сервер.
JavaScript: режимы, подбор правки, защиты, неизменность проекта, формат JSON.
Браузер + OpenVSP: реальный ввод, автоцикл ремонта, отмена, сохранение крыла,
экспорт/внешний TRI, смена режима, устаревшие ответы, офлайн и узкий экран.
В учебном примере нативный наклон снизился 54,0093° → 47,7609°;
максимальное смещение 0,0450846 ft при бюджете 0,05 ft; вне зоны — 0.
При M = 1,5 угол Маха 41,8103°: риск остаётся. Это пример частичного улучшения.

Проверены MQ-28 B, MQ-20, SAAB FCAS, YFQ-44, Spirit Mosquito и OKRUG
при M = 0,5 / 1,5 / 2. Носы и торцы некоторых геометрий недопустимы
в сверхзвуковой постановке исследованного MachLine. Прежняя успешная
проверка VSPAERO автоматически не переносится на MachLine.
Четыре контрольных STOP воспроизведены запуском неизменённого исходника.
Закрытое учебное тело из восьми треугольников рассчитано при M = 0,5 и 2
с solver_status_code = 0. Это проверки интеграции, не валидация АДХ самолётов.
Никакие экспериментальные аэродинамические данные не использованы.

НЕ РЕАЛИЗОВАНО В ЭТОМ ЭТАПЕ

Приложение не запускает MachLine для пользовательской модели и не предсказывает
Cp. Матрица влияния, обусловленность, GMRES, фактические контрольные точки
после клонирования и отладка следа остаются отдельным расчётным этапом.
Диагностический Cart3D экспорт не заменяет окончательную сетку пересечений.
Для неё можно отдельно загрузить готовый TRI. Полного поиска пересечений
панелей нет; близость центров не гарантирует отсутствия пересечения.
Конечная выборка поверхности ограничивает строгость проверки ремонта.
